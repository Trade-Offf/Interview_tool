# 🗂️ Interview Tool — 面试评价卡片生成器

> 朋友，面试完还要对着空白文档发呆写评价？
> 把录音文字往这一扔，5 分钟拿下一张干净好看的评价卡片。

---

## 你现在是不是这样？

- 面完试坐在那儿，脑子里都是候选人说的话，不知道从哪开始写
- 写出来的评价全是流水账，领导看了一脸问号
- HR 催你出结论，你还在 Word 里调格式
- 每次面试评价格式不一样，留档乱七八糟

**这个工具就是来解决这件事的。**

---

## 能做什么

把面试录音的逐字稿（或你自己整理的评价文字）丢进来，自动生成一张这样的卡片：

- ✅ 面试结论 Badge（通过 / 不通过 / 待定）
- ✅ 建议级别 + 高级判断提示
- ✅ 本轮考察内容总览
- ✅ 候选人表现段落（有理有据）
- ✅ 优点 / 风险点双栏对比
- ✅ 综合结论
- ✅ 二面安排提醒
- ✅ 右上角一键导出高清 PNG，截图发飞书不丢人

---

## 怎么用

### 方式一：粘贴逐字稿（最省力）

把面试录音转出来的文字**直接往 Cursor 对话框里一粘**，说一句：

```
帮我生成面试评价卡片
```

完事。Agent 会自动读出考察点、分析表现、提炼优缺点、判断结论，生成 HTML 文件。

### 方式二：粘贴你自己整理的评价文字

如果你已经写好了评价草稿，格式随意，说一句：

```
帮我生成面试评价卡片：

候选人：xxx / EnglishName
岗位：xxx
面试结论：通过
建议级别：中级
...（其余内容随手粘）
```

同样搞定。

---

## 安装方式（1 分钟）

把 `interview-card/` 目录复制到你本地 Cursor 的 skills 文件夹：

```bash
# macOS / Linux
cp -r interview-card ~/.cursor/skills/

# Windows（PowerShell）
Copy-Item -Recurse interview-card $env:USERPROFILE\.cursor\skills\
```

重启 Cursor，完成。之后直接在对话里说"生成面试卡片"就行，不用记其他命令。

生成的文件默认保存在 `~/Desktop/面试评价/` 文件夹，文件名自动带岗位和候选人名字。

---

## 文件结构

```
interview-card/
├── SKILL.md        ← Cursor Agent 读的指令（字段解析 + 逐字稿提炼规则）
└── template.html   ← 卡片的 HTML/CSS 设计模板
```

---

## 注意事项

- 候选人卡片（生成的 HTML 文件）含个人信息，**请不要上传到公开仓库**
- 导出截图功能依赖 html2canvas CDN，需要联网
- 不要改 `template.html` 里的 `:root` 色板变量，否则整体风格会乱掉
