# 🗂️ Interview Tool — 面试评价卡片生成器

> 朋友，面试完还要对着空白文档发呆写评价？
> 把录音文字往这一扔，5 分钟拿下一张干净好看的评价卡片。

---

## 你现在是不是这样？

- 面完试坐在那儿，脑子里都是候选人说的话，不知道从哪开始写
- 写出来的评价全是流水账，领导看了一脸问号
- HR 催你出结论，你还在 Word 里调格式
- 每次面试评价格式不一样，留档乱七八糟

**这个工具就是来解决这件事的。**

---

## 能做什么

把面试录音的逐字稿（或你自己整理的评价文字）丢进来，自动生成一张这样的卡片：

- ✅ 面试结论 Badge（通过 / 不通过 / 待定）
- ✅ **技术岗（R&D）分项评分表**：一面/二面各 6 项关注点，0-5 分打分 + 简评 + 平均分
- ✅ 候选人表现段落（有理有据）
- ✅ 优点 / 风险点双栏对比
- ✅ 综合结论
- ✅ **建议定级**（每轮单独给，如 `P6` / `中级`）+ **下一轮面试官重点考察**（一面/二面产出，供下一轮参考）
- ✅ 安排提醒（有异常情况时才出现）
- ✅ 右上角两个按钮：**一键导出高清 PNG** + **一键复制文字版评价**，方便贴进飞书审批表单

> 目前分项评分表只支持**技术岗（R&D）**，一面/二面题库已配置，三面题库还没定（AI 会自主判断考察维度并照常打分）。其他岗位（运营/风控/BD/实习生）暂时还是自由格式的优缺点描述，等 HR 把题库配好再升级。

---

## 怎么用

### 方式一：粘贴逐字稿 + 说清楚轮次和岗位（最省力，推荐）

把面试录音/妙记转出来的文字**直接往 Cursor 对话框里一粘**，顺手带上轮次和岗位：

```
帮我出一下 Rico 的一面面评，岗位是前端

[粘贴逐字稿 或 甩一个妙记链接]
```

Agent 会先检查有没有缺关键信息（轮次、岗位没说清会先问你），再自动读出考察点、逐项打分、分析表现、提炼优缺点、判断结论和定级，生成 HTML 文件。

> 轮次（一面/二面/三面）必须说清楚，因为对应的评分维度不一样；没提岗位的话 Agent 会先问，不会瞎猜。

### 方式二：粘贴你自己整理的评价文字

如果你已经写好了评价草稿，格式随意，说一句：

```
帮我生成面试评价卡片：

候选人：xxx / EnglishName
岗位：xxx
轮次：一面
面试结论：通过
...（其余内容随手粘）
```

同样搞定，不是技术岗或没有打分维度的话，会自动退化成自由格式的优缺点描述。

### 卡片生成后：怎么交付
右上角两个按钮：

| 按钮 | 用途 |
| --- | --- |
| 复制文字版评价 | 一键把打分/结论/定级整理成一段纯文字，粘贴进审批表单的文字栏 |
| 导出截图 | 生成一张 PNG，插入审批表单的图片栏 |

⚠️ 飞书审批目前不支持程序化写入已有实例，**贴进审批表单这一步还是要人工做**，工具帮你省的是"看逐字稿 + 手写评价 + 打分"这一大块。

### 二面/三面怎么衔接上一轮
一面卡片里的"下一轮面试官重点考察"，把这段话转给下一轮面试官参考即可（目前靠人工转达，没有做自动传递）。

## 安装方式（1 分钟）

把 `interview-card/` 目录复制到你本地 Cursor 的 skills 文件夹：

```bash
# macOS / Linux
cp -r interview-card ~/.cursor/skills/

# Windows（PowerShell）
Copy-Item -Recurse interview-card $env:USERPROFILE\.cursor\skills\
```

重启 Cursor，完成。之后直接在对话里说"生成面试卡片"就行，不用记其他命令。

生成的文件默认保存在 `~/Desktop/面试评价/` 文件夹，文件名自动带岗位、轮次和候选人名字，例如：

```
~/Desktop/面试评价/面试评价_前端_一面_Rico.html
```

## 文件结构

```
interview-card/
├── SKILL.md        ← Cursor Agent 读的指令（字段解析 + 逐字稿提炼规则）
└── template.html   ← 卡片的 HTML/CSS 设计模板
```

## 注意事项

- 候选人卡片（生成的 HTML 文件）含个人信息，**请不要上传到公开仓库**
- 导出截图功能依赖 html2canvas CDN，需要联网；复制文字版评价用的是浏览器 clipboard API，本地打开一般也能用
- 不要改 `template.html` 里的 `:root` 色板变量，否则整体风格会乱掉
- 分项评分表目前只覆盖**技术岗（R&D）**的一面/二面，题库来自 HR 维护的评估表；三面和其他岗位（运营/风控/BD/实习生）还没有配置好题库
- 回填审批流程做不到自动化（飞书审批 API 不支持写入已有实例），生成的图片/文字仍需要人工贴进审批表单
